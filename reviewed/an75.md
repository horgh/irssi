## What it changes
Simplifies `.github/workflows/termuxpkg.yml`. It removes the custom
`termux_step_configure_meson()` override (which manually invoked `$TERMUX_MESON`
and `sed`-injected the perl binary line into `$TERMUX_MESON_CROSSFILE`), relying
instead on Termux's standard meson configure step. The perl-specific meson
binary definition is now written to a separate cross file
(`$TERMUX_PKG_TMPDIR/meson-miniperl-cross-$TERMUX_ARCH.txt`) inside
`termux_step_pre_configure()`, and that file is passed to meson via an added
`--cross-file` entry in `TERMUX_PKG_EXTRA_CONFIGURE_ARGS`. The
`perl = ['.../miniperl', '-I...']` definition is carried over verbatim.

## Files touched
- `.github/workflows/termuxpkg.yml`

## Release-safety findings
None — safe to release. This is a CI-only change to the Termux package build
workflow. It does not touch irssi source, build system, or anything shipped to
end users; it cannot break the released artifact. The cross-file content and
perl resolution logic are preserved; the only difference is using the standard
configure step plus an extra cross file rather than a hand-rolled meson invocation.
