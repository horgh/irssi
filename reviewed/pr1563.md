# #1563 — Add a Void Linux Docker build to GitHub Actions

- Commit: 824c1aa3
- Verdict: SAFE

## What it changes
Adds a single new GitHub Actions workflow file, `.github/workflows/voiddocker.yml`,
that runs a CI build/test of Irssi inside a Void Linux glibc container. It has two
jobs: `dist` (installs deps via xbps, runs `utils/make-dist.sh`, uploads the
tarball artifact) and `install` (downloads the tarball, builds with meson/ninja,
runs `ninja test`, and performs an automated headless irssi launch test). Triggers
on push to master, pull_request, and workflow_dispatch.

## Files touched
- `.github/workflows/voiddocker.yml` (new)

## Release-safety findings
None — safe to release. This is a CI-only addition. It introduces no changes to
