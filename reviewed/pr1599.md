# #1599 — Update syncdocs.sh to sync the New-users and qna docs, dropping faq and startup-HOWTO

- Commit: 81887a62
- Verdict: SAFE

## What it changes
Reworks the maintainer-only helper `utils/syncdocs.sh` to download the
QNA and New-users guides from irssi.org instead of FAQ/startup-HOWTO/design,
adds an `download_it_nested` function (perl-driven) to assemble the
multi-page QNA doc, adjusts the HTML-cleanup regexes, adds a header-mark
perl filter for the html->txt conversion, and exports
`LC_ALL=en_IE.utf8`. It also commits the regenerated doc artifacts:
new `docs/New-users.{html,txt}` and `docs/qna.{html,txt}`.

## Files touched
- utils/syncdocs.sh
- docs/New-users.html, docs/New-users.txt (new)
- docs/qna.html, docs/qna.txt (new)

## Release-safety findings
None — safe to release.

`syncdocs.sh` is a manual maintainer tool and is not invoked by the meson
build or at runtime (confirmed: no build file references it), so its
internal correctness, its `perl`/`eval`/locale dependencies, and the
en_IE.utf8 locale requirement cannot affect the release build or users.
The build still succeeds: `docs/meson.build` continues to reference the
existing faq/startup-HOWTO/design files, which remain present in the tree
(this commit does not delete them). No source, ABI, or runtime behavior
is affected.

Note (not a blocker): the newly added `qna.*` and `New-users.*` files are
NOT listed in `docs/meson.build`, so they will not be installed for end
users; the still-listed faq/startup-HOWTO files will continue to install.
This is a documentation-packaging completeness gap, not a regression —
nothing that previously installed stops installing, and nothing breaks.

## Interactions with related changes
None.
