# an#64, 58efc637 — Remove the autotools build system in favour of meson

- Commit: 58efc637
- Verdict: SAFE

## What it changes
Removes the entire autotools build system (configure.ac, autogen.sh, all
Makefile.am files, the m4/ macros, glib-tap.mk, tap-driver.sh, tap-test,
irssi-1.pc.in, and the perl Makefile.PL.in templates) in favour of the
already-existing meson build. Net: ~3867 deletions, ~118 additions across
65 files. The meson build (meson.build + per-directory meson.build files)
was introduced earlier (commit db16a0a8) and already coexisted, so this
commit removes the now-redundant second build path rather than introducing
the new one.

Substantive additions/modifications:
- New `utils/make-dist.sh`: builds the release tarball from a fresh
  `git clone --no-local` of the repo, parses name/version out of
  meson.build via perl, generates a temporary setup.cfg, and runs
  `setuptools sdist` driven by the new `MANIFEST.in`, then xz/gzip's it.
- New `MANIFEST.in`: declares which committed files go into the sdist
  (meson.build everywhere, src/tests sources, perl sources, utils scripts,
  irssi.conf, themes, docs, help/in/[a-z]*.in, scripts, NEWS; prunes Build,
  dist, egg-info, subprojects/*/).
- New `utils/check-perl-hash.sh`: validates hv_store key lengths; invoked by
  make-dist.sh.
- `.github/workflows/check.yml`: drops the autotools build/test matrix legs
  and the `make dist` via autogen; dist now runs `./utils/make-dist.sh`.
- `src/fe-text/meson.build`: removes `install_rpath` on the `irssi`
  executable (commit e692f85f, requested by distro packagers).
- `utils/{syncdocs,syncscripts}.sh`: sentinel file check changed from
  `configure.ac` to `irssi.conf`.
- `utils/{irssi-version,file2header}.sh`: shell modernization/quoting,
  functionally equivalent.
- INSTALL/.gitignore housekeeping.

## Release-safety findings
None — safe to release.

Notes considered and cleared:
- meson is the sole supported build after this and is fully present at this
  commit (all per-directory meson.build files exist; version header via
  utils/irssi-version.sh + custom_target, config/theme via file2header.sh
  are all wired through meson). The removal does not leave the project
  unbuildable.
- Removal of `install_rpath` on the irssi executable: the executable links
  only against in-tree static libraries (`.a`), not shared libs installed
  into prefix/libdir, so an rpath there provided nothing at runtime. It was
  removed at packager request because an RPATH into a standard libdir is a
  known packaging defect. The separate perl-module rpath handling
  (src/perl/meson.build) is untouched. No runtime regression.
- make-dist.sh builds from a clean `git clone --no-local`, so only committed
  files are packaged — safer than the old autotools `make dist` (no stray
  uncommitted/build artifacts can leak in). The name/version perl regexes
  match the actual `project('irssi', ... version : '...')` form.
- MANIFEST.in glob `docs/help/in/[a-z]*.in` covers every help source file
  (all are lowercase-leading); `global-include meson.build` and the
  recursive src/tests/perl includes cover the build inputs needed by meson.
- No lingering functional references to removed autotools files; only inert
  .gitignore lines and a CI step *name* "make dist" remain.
- `make-dist.sh` adds a build-time dependency on python3 + setuptools, but
  that already existed for meson and is reflected in the CI deps. This is a
  release-engineering/maintainer-side tool, not something end users run.
