# #1565 — Fix the Void Linux GitHub Actions workflow

- Commit: 4b338242
- Verdict: SAFE

## What it changes
A two-line change to the Void Linux CI workflow. It (1) downloads
`render.pl` from the irssi-import/actions-irssi repo into `~/render.pl` and
makes it executable, and (2) replaces `gsed` with `sed` in the `find ...
-exec` command that strips GITHUB env lines from `testlog.txt`. On Void
Linux the native `sed` is GNU sed, so `gsed` does not exist; the prior
command would fail.

## Files touched
- `.github/workflows/voiddocker.yml`

## Release-safety findings
None — safe to release. This is a CI-only change. It does not touch any
source, build configuration, or shipped artifact, so it cannot affect the
released binary or break a build for users. The `curl -SLf` fetch is over
HTTPS to a project-controlled GitHub repo and only runs inside the CI
container.
