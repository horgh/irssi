# #1521 — Update GitHub Actions to newer Node.js versions

- Commit: bb4ed2b1
- Verdict: SAFE

## What it changes
Bumps GitHub Actions versions in three CI workflows from the Node.js 16-based
`v3` to the Node.js 20-based `v4` releases of `actions/upload-artifact` and
`actions/download-artifact`. No source code, build system, or shipped content
is touched.

## Files touched
- .github/workflows/abicheck.yml
- .github/workflows/check.yml
- .github/workflows/termuxpkg.yml

## Release-safety findings
None — safe to release. The diff is confined to CI workflow definitions and
cannot affect the irssi binary, libraries, ABI, or distributed tarball. The
known `upload-artifact@v4` behavior changes (immutable artifacts, no duplicate
artifact names, changed download path defaults) are CI-pipeline concerns only;
even if a workflow broke, it would not affect what users receive in the
release.

## Interactions with related changes
None.

## NEWS accuracy
Accurate. The NEWS line describes a GitHub Actions Node.js version bump, which
matches the diff.
