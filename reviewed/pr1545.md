# #1545 — Bump actions/upload-artifact from the deprecated v1 to v4 in CI

- Commit: 344dd0fb
- Verdict: SAFE

## What it changes
Bumps `actions/upload-artifact` from the deprecated/defunct `@v1` to `@v4`
in two GitHub Actions workflow files. No source code, build system, or
shipped artifacts are affected.

## Files touched
- .github/workflows/cifuzz.yml
- .github/workflows/clangformat.yml

## Release-safety findings
None — safe to release.

CI-only change. The main v4 breaking behavior (a run may not upload two
artifacts with the same name) is not triggered here: in cifuzz.yml the
artifact name is `${{ matrix.sanitizer }}-artifacts`, which is unique per
matrix leg, and clangformat.yml has a single upload step with a fixed name.
Both upload steps only run `if: failure()`, so they have no effect on
normal/passing runs. Nothing in this change is part of the released irssi
binary or distribution tarball.

None.
