# #1588 — Increase the default scrollback_lines from 500 to 5000

- Commit: bab97b4c
- Verdict: SAFE

## What it changes
Changes a single default value: the `scrollback_lines` setting registered via
`settings_add_int("history", "scrollback_lines", ...)` in
`gui_printtext_init()` goes from 500 to 5000. No logic changes.

## Files touched
- src/fe-text/gui-printtext.c (one line)

## Release-safety findings
None — safe to release.

- Only the default for new/unset configs changes. Existing users who have
  `scrollback_lines` set in their config are unaffected.
- The value flows into `remove_old_lines()` where it is compared against
  `view->buffer->lines_count` and used in `scrollback_lines +
  scrollback_burst_remove` (default 10 → 5010). `scrollback_lines` is a plain
  `int`; 5010 is nowhere near INT_MAX, so no overflow/UB. The `== 0` special
  case and the removal loop are unchanged and unaffected.
- The only practical effect is higher per-window memory use, since up to 10x
  more scrollback lines may be retained per buffer. This is a deliberate,
  bounded behavior change, not a correctness or stability risk. No injection
  or other security surface is touched.

## Interactions with related changes
None.

## NEWS accuracy
Accurate. NEWS states "Increase the default scrollback_lines from 500 to
5000", which exactly matches the diff.
