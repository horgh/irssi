# #1440 — Build the Termux package from a git source URL

- Commit: fe8f2a5d
- Verdict: SAFE

## What it changes
Changes a single line in the Termux package CI workflow: the
`TERMUX_PKG_SRCURL` is switched from a plain `file://` URL to a `git+file://`
URL, so the termux package builder treats the source as a git checkout rather
than a tarball. The surrounding workflow already creates a `v$version` git tag
(line 69) for this consumption.

## Files touched
- `.github/workflows/termuxpkg.yml`

## Release-safety findings
None — safe to release. This is a CI/packaging-only change with no effect on
the irssi source, build artifacts shipped to end users, ABI, runtime behavior,
or security surface. It only affects how an experimental GitHub Actions job
fetches the source when building a Termux .deb. No injection or correctness
concern in the released software.

## Interactions with related changes
None.

## NEWS accuracy
Accurate. The change builds the Termux package from a git source URL exactly
as described.
