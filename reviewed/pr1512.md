# #1512 — Fix missing shell quotes in the irssi-version.sh helper script

- Commit: 91dac0e5
- Verdict: SAFE

## What it changes
Quotes the `$1` argument in the `grep '^v' "$1"/NEWS` invocation in
`utils/irssi-version.sh`, so the source-tree path is treated as a single
word. This makes the script work when the build/source path contains
spaces or shell glob characters. One-line change; no behavior change for
paths without special characters.

## Files touched
- utils/irssi-version.sh

## Release-safety findings
None — safe to release. The change is a strictly safer form of an existing
command. For normal paths the result is identical; for paths with spaces it
fixes a previously-broken case. No injection risk introduced (quoting
reduces, not increases, word-splitting/globbing exposure). Note the change
does not quote the remaining `$1/.git` uses on lines 15/23, but those were
not in scope and are unchanged from prior behavior.

## Interactions with related changes
None.

Accurate.
