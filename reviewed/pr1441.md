# #1441 — Update GitHub Actions workflows for deprecated set-output and artifact actions

- Commit: 3fb147ec
- Verdict: SAFE

## What it changes
Updates GitHub Actions CI workflows only. Replaces the deprecated
`::set-output` command with the `$GITHUB_OUTPUT` file mechanism (in
abicheck.yml), and bumps `actions/upload-artifact` and
`actions/download-artifact` from `@v2` to `@v3` across abicheck.yml,
check.yml, and termuxpkg.yml.

## Files touched
- .github/workflows/abicheck.yml
- .github/workflows/check.yml
- .github/workflows/termuxpkg.yml

## Release-safety findings
None — safe to release. These are CI-only changes that do not touch any
source, build configuration, or shipped artifact. The `$GITHUB_OUTPUT`
rewrites are the standard replacement for the deprecated `::set-output`
syntax and preserve the same output names (base_abi, merge_abi). No
injection concern: the echoed values come from internal build commands,
not untrusted input. Worst case of any error here is a CI failure, not a
broken release.
