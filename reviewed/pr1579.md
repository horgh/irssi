# #1579 — Fix the xbps Void Linux GitHub Actions workflow

- Commit: cc24b2c5
- Verdict: SAFE

## What it changes
Adds `xbps-install -Syu xbps || :` before the existing `xbps-install -Syu`
in two jobs of the Void Linux GitHub Actions workflow. This first updates
the xbps package manager itself (ignoring failure via `|| :`), which is the
recommended Void Linux upgrade procedure to avoid the "xbps needs updating"
abort, then proceeds with the full system upgrade and package install.

- .github/workflows/voiddocker.yml

## Release-safety findings
None — safe to release. This affects only CI infrastructure, not the shipped
irssi source or build artifacts. No injection or runtime concern; the added
commands are static. A failure of the new line is intentionally swallowed
with `|| :`, which cannot worsen the prior behavior.
